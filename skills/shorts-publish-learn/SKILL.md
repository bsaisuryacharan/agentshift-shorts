name: shorts-publish-learn
description: Package, deliver and learn from a finished Short. Use after QA passes.
---
1. Deliver via Telegram (review mode): MP4 + title, description with sources, tags, pinned comment, post time 19:00 IST, credits used.
2. Publish only when `PUBLISH_MODE=schedule` and OAuth audit allows public uploads.
3. After 48 h pull Shorts analytics (avg viewed %, engaged views, subs). Append to docs/LESSONS.md: topic, format, hook, scores, result. Keep what beat the channel baseline; drop what did not; do not generalise from one video.
4. Rotate format: never the same visual format three Shorts in a row.
