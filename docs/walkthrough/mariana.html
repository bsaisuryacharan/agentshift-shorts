Where everything runs (including Claude in Telegram)

You, in Telegram→Cloudflare Worker (relay, ~1 s)→GitHub Actions: a fresh Ubuntu machine→back to Telegram
  • Telegram is only the chat window. Nothing runs there.
  • Claude's commands (reading code, tests, gh, the orchestrator) run on a temporary GitHub Actions machine started by the chat workflow for each message. It checks out the repository, runs Claude Code, then is deleted. Only memory, conversation and Claude's pull requests are kept in the repository.
  • Making a Short runs the same way, on its own machine (free-daily or orchestrator workflow). Nothing runs on your Mac.
